# Future AI Development Workflow

1. Agent reads `/docs` (especially [README.md](./README.md) — Documentation First).  
2. Updates Feature Registry, feature doc, package impact; Product Decision / AI docs if needed.  
3. Human or Product Owner approves documentation when required.  
4. Agent implements code to match the approved docs.  
5. Runs manual/automated checks.  
6. Same change set (or linked PRs) keeps docs and code aligned.  
7. Human reviews commercial and security impact.
