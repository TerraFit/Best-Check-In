# Common Mistakes

1. Duplicating plan matrices.  
2. Frontend-only paywalls on exports.  
3. Recommending Enterprise for every upsell.  
4. Treating Business as “Pro + city map” only.  
5. Shipping USD upgrade copy.  
6. Claiming Housekeeping/Lost & Found as done when Missing.  
7. Cross-tenant queries.  
8. Editing application code on a documentation-only request.
