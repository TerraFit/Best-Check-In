# Common Mistakes

1. **Implementing features before updating documentation** (violates Documentation First).  
2. Duplicating plan matrices.  
3. Frontend-only paywalls on exports.  
4. Recommending Enterprise for every upsell.  
5. Treating Business as “Pro + city map” only.  
6. Shipping USD upgrade copy.  
7. Claiming Housekeeping/Lost & Found as done when Missing.  
8. Cross-tenant queries.  
9. Editing application code on a documentation-only request.  
10. Shipping a feature PR without Feature Registry + feature doc + package impact review.
