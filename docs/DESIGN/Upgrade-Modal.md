# Upgrade Modal

**Approved Direction** pattern for soft-locks.

## Must include

- Feature attempted + why it matters  
- Required / recommended package (next tier)  
- 4–6 benefits  
- Current → recommended comparison  
- CTA: Upgrade Now · Maybe Later · Compare Packages  

## Must not

- Bare “Upgrade Required”  
- USD prices when product is ZAR  
- Always recommend Enterprise
