# Definition of Done

## Documentation First (mandatory for new/changed features)

- [ ] Feature Registry updated  
- [ ] Feature documentation updated (`docs/FEATURES/`)  
- [ ] Package impact reviewed (minimum package, lock/enforce, upsell)  
- [ ] Product Decision entry added if commercial or architecture policy changed  
- [ ] AI documentation updated if architecture / permission / agent rules changed  
- [ ] Documentation reviewed/approved before or with the implementation PR  

## Implementation

- [ ] Behaviour matches Approved Direction or explicit exception  
- [ ] No secrets committed  
- [ ] Tenant isolation preserved  
- [ ] Soft-lock/upgrade UX if package-gated  
- [ ] Backend enforcement for sensitive operations  
- [ ] Manual QA of happy path
