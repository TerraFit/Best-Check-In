# Development Standards

1. **Documentation First** — see [docs/AI/README.md](../AI/README.md). No architectural, commercial, or user-facing feature ships without the required doc updates.  
2. Read [docs/AI](../AI/) and relevant product docs before package-scoped work.  
3. Do not change commercial package meaning without a Product Decision.  
4. Prefer small PRs.  
5. Update Feature Registry when adding features.  
6. No secrets in git.
